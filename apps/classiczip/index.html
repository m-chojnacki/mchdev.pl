ClassicZip

Zip, 7z, RAR, tar and dozens more. Browse archives like folders, extract, test and edit them in place, and create encrypted or split archives.

ClassicZip is a fast, no-nonsense file archiver for your Mac. Open an archive and see everything inside in one classic file list, with sizes, packed sizes, dates, CRCs and compression methods, then work with it like a folder.

Open almost anything

Browse and extract zip, 7z, RAR, tar, gzip, bzip2, xz, Zstandard, ISO, DMG, CAB, WIM, ARJ, LZH, CPIO, XAR, RPM and DEB packages, Windows installers, virtual disk images (VHD, VMDK, VDI, QCOW) and more. Archives split into volumes (.001, .002, …) open as one.

Create archives your way

  • 7z, zip, tar, WIM, gzip, bzip2, xz, tar.gz, tar.bz2 and tar.xz
  • Compression levels from Store to Ultra, with a choice of method (LZMA2, LZMA, PPMd, BZip2, Deflate, Deflate64), dictionary size, word size and CPU threads
  • Solid 7z archives for the best ratio
  • Split into volumes of any size, with presets for CD, DVD, FAT and Blu-ray
  • Keep symbolic links and modification, creation and access times

Protect with a password

Encrypt 7z and zip archives with AES-256, and hide the file names too in 7z. Open password-protected zip, 7z and RAR archives: ClassicZip asks for the password only when it needs it.

Edit archives in place

  • Add files, with their own compression and password settings
  • Rename, delete, create folders and move items by dragging, right inside the archive
  • Open a file in its default app and, once you save it, put the changed version back into the archive
  • Edit zip comments

Extract and verify

  • Extract everything or just the selection, with full, current or no pathnames, into a subfolder or straight into the destination
  • Drag files out of the archive into Finder
  • Test archives for errors
  • Calculate CRC-32, SHA-256, SHA-1, SHA-512 and MD5 checksums of files inside an archive and copy them in shasum format
  • Search the archive by file name

At home on your Mac

  • “Compress with ClassicZip” and “Extract with ClassicZip…” right in Finder’s context menu
  • Drop files onto an archive window to add them
  • A welcome window with your recent archives
  • A built-in benchmark that measures your Mac’s compression and decompression speed
  • Native, sandboxed, with no network access and no data collection

Powered by the open-source 7-Zip engine.
